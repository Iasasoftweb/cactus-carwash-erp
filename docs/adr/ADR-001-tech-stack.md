# ADR-001 — Stack inicial

## Estado
Aprobado.

## Decisión
Usar React + TypeScript + Vite para web; NestJS para API; MySQL y Prisma para persistencia; pnpm y Turborepo para el monorepo.

## Consecuencias
- Tipos consistentes en todo el proyecto.
- Desarrollo modular.
- Buen soporte para APIs, UI táctil y evolución comercial.
- Se requiere disciplina de migraciones, auditoría y contratos entre módulos.
